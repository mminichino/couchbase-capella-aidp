# couchbase-capella-aidp Provider

Terraform provider for Couchbase Capella AI Data Plane (AIDP) APIs.

Manage Capella AI Data Plane resources that are not covered by the official `couchbase-capella` provider.

## Example Usage

```terraform
terraform {
  required_providers {
    couchbase-capella-aidp = {
      source = "mminichino/couchbase-capella-aidp"
    }
  }
}

provider "couchbase-capella-aidp" {
  authentication_token       = var.couchbasecapella_auth_token
  global_api_request_timeout = 300
}

variable "couchbasecapella_auth_token" {
  type      = string
  sensitive = true
}
```

## Schema

### Optional

- `authentication_token` (String, Sensitive) Capella API Token that serves as an authentication mechanism. May be set via the CAPELLA_AUTHENTICATION_TOKEN environment variable.
- `global_api_request_timeout` (Number) Global API request timeout in seconds. May be set via the CAPELLA_GLOBAL_API_REQUEST_TIMEOUT environment variable. Defaults to 300. Value must be greater than or equal to 300.
- `host` (String) Capella Public API HTTPS Host URL. May be set via the CAPELLA_HOST environment variable. Defaults to https://cloudapi.cloud.couchbase.com

## Authentication

Set credentials in the provider block or via environment variables:

| `host` | `CAPELLA_HOST` |
| `global_api_request_timeout` | `CAPELLA_GLOBAL_API_REQUEST_TIMEOUT` |
